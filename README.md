# Redeem Code Shop

Starter website for a redeem-code store.

## Included
- Product catalogue
- Three code types per product
- Checkout flow
- Order/code delivery API
- SQLite database
- Admin API for adding products and redeem codes
- Razorpay integration placeholders

## Run
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Copy `.env.example` to `.env` and add your payment credentials.
5. Run `npm start`
6. Open http://localhost:3000

The payment integration is intentionally left in test/configuration mode until you add your own payment-gateway credentials.
